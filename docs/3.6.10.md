# GitHub Desktop 3.6.10 Windows x64 汉化适配

本版本以官方 **3.6.10 Windows x64** 文件为底包，移植上游中文词条，并补充当前版本的工作树、Copilot、通知和登录等文案。只支持对应版本和架构，不使用旧版本脚本冒充新版本。

## 使用

源码运行时，GUI 和 `python gui/cli.py versions` 会自动发现 `dictionaries/3.6.10/`。

使用已有的单文件汉化工具时，将本仓库的 `dictionaries/3.6.10/` 目录复制到汉化工具 EXE 同级的 `dictionaries/` 下，再重新打开工具、选择 **3.6.10**。目录内的 `main.js` 和 `renderer.js` 必须成对保留。

应用前关闭 GitHub Desktop。本次适配及验证只生成仓库内文件，没有覆盖本机客户端，也没有修改 Git 配置。

## 适配时修正的上游规则

- 将 `Fetching` 限定在显示文案，避免误改 `startBackgroundFetching` / `stopBackgroundFetching` 方法名。
- 只翻译界面中的 `Notifications` 等文字，保留同名枚举、比较值和其他程序常量。
- 保留模板插值、插值顺序及外部编辑器的后备值，补齐压缩变量改名后的词条。
- 修复 `Git ignore` 词条中缺失的引号。
- 将 Fetch 的文案改为“获取”，避免误写成“拉取然后推送”。
- 排除宽泛的 `"commits")` 替换，保留 `this.increment("commits")` 使用的统计字段名。

## 重新生成与检查

需要 Python 3.8+、Node.js，以及 Acorn **8.15.0**。以下命令在仓库根目录运行；下载的官方原包和解析器放在已忽略的 `.work/` 下。

```powershell
npm install --prefix .work/js-parser --no-save acorn@8.15.0
python scripts/build_3_6_10.py --package .work/GitHubDesktop-3.6.10-x64-full.nupkg --acorn .work/js-parser/node_modules/acorn/dist/acorn.mjs
python gui/cli.py versions
```

生成脚本先在临时目录中适配两个文件，调用 [verify_translation.mjs](../scripts/verify_translation.mjs) 检查语法及 AST；两份文件都验证通过后才写入字典目录。它不操作 GitHub Desktop 安装目录。

验证器逐节点比较官方文件与汉化文件，只允许字符串字面量及模板文本差异，禁止改变标识符、函数调用结构、控制流程、模板表达式顺序、对象键、枚举及比较常量，并核对 `3.6.10`、`ucrt64`、凭据助手和后台获取方法标识。可变更的函数实参限定在针对本版本审查过的显示和日志调用中；这项静态检查与文案用途审查共同降低误改程序常量的风险。

应用、备份和还原流程在临时的 `app-3.6.10/resources/app` 目录验证。尚未做真实客户端的启动、登录、推送和拉取测试；少数未收录的文案可能仍显示英文。
